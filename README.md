# Yared Abebaw — Portfolio

A responsive, single-page developer portfolio built with plain HTML, CSS, and JavaScript. It is intentionally separate from the Cookly application repository.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build step or package installation is required. Google Fonts are loaded from the web; the page falls back to system fonts if they are unavailable.

## Deploy to Vercel
1. Create a new GitHub repository, for example `yared-abebaw-portfolio`.
2. Upload the contents of this folder (not the enclosing ZIP).
3. In Vercel, choose **Add New → Project**, import the repository.
4. For a static site, leave the framework preset as **Other**; leave build command and output directory empty.
5. Deploy.

## Before publishing
- Confirm that the Cookly repository URL is correct and decide whether to make that repository public. The portfolio currently labels it as potentially private.
- Add a real profile photo if desired. No photo or unverified social links are fabricated.
- Add live demo links only for projects that are actually deployed.
- Review every project description and technology tag for accuracy.
- The contact button opens the visitor's email app using `mailto:`.

## Customize
- Update content in `index.html`.
- Change colors, spacing, and responsive styles in `styles.css`.
- Navigation behavior and the current year are handled in `script.js`.
